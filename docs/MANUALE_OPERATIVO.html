0. Installazione app e permessi (Android · iOS)

Prima del servizio in campo ogni volontario deve avere gestSQUADRE installata e i permessi attivi (posizione + notifiche). Il Chief TOC coordina distribuzione APK/IPA e raccolta UDID per iPhone.

0.1 Chi fa cosa

RuoloAndroid (APK)iOS (IPA / iPhone)
Chief TOC / tecnico Distribuisce file APK aggiornato ai volontari Raccoglie UDID, registra iPhone su Apple Developer, distribuisce IPA o TestFlight
Volontario Installa APK e attiva permessi Invia UDID al TOC, installa app, attiva permessi, test login

ANDROID 0.2 File APK — dove e come si ottiene

  • File: gestSQUADRE_KMP_dev_1.0.18.apk (o versione indicata dal TOC).
  • Chi lo genera: tecnico su PC Windows con build KMP (kmp-dev.bat).
  • Come arriva al volontario: USB, email, link cloud, WhatsApp, QR (stesso file per tutti gli Android).
  • Package app: com.ansmi.gest_squadre — icona gestSQUADRE.

ANDROID 0.3 Installazione APK sul telefono

  1. Apri il file APK ricevuto (app File, Gmail, Drive, ecc.).
  2. Se Android chiede conferma: Impostazioni → Consenti installazione da questa app (o «Origini sconosciute» su modelli precedenti).
  3. Tocca Installa → al termine Apri.
  4. Alternativa tecnico (USB): attiva Opzioni sviluppatore → Debug USB sul telefono, collega al PC, autorizza il computer, poi adb install -r gestSQUADRE_....apk.

0.4b Android — «Gestisci l'app se inutilizzata» (molto importante)

Su molti telefoni Android (Samsung, Xiaomi, Pixel, ecc.) c'è un'opzione che revoca da sola GPS e notifiche se l'app non viene aperta per qualche giorno. Se resta attiva, il volontario sembra loggato ma il TOC non vede più la posizione e non arrivano push.

In Impostazioni → App → gestSQUADRE (o «Info app»), cerca «Gestisci l'app se inutilizzata» / «Rimuovi autorizzazioni se l'app non viene usata» e disattivala (spunta/toggle OFF). Su alcuni modelli è sotto Autorizzazioni o nel menu ⋮ in alto a destra.
  1. Impostazioni → App → gestSQUADRE.
  2. Apri Gestisci l'app se inutilizzata (nome leggermente diverso a seconda del produttore).
  3. Disattiva Rimuovi le autorizzazioni se l'app non viene usata.
  4. Ricontrolla che Posizione e Notifiche siano ancora consentite.

Dopo ogni aggiornamento APK o cambio telefono, ripetere questa verifica insieme al login di prova.

iOS 0.5 Panoramica installazione iPhone

  • Su iPhone non si usa un file APK: l'app è distribuita come IPA (Ad Hoc), via TestFlight, oppure installata dal tecnico con Mac + Xcode.
  • Bundle ID: com.ansmi.gestsquadre.
  • Per distribuzione Ad Hoc (tipica in evento): ogni iPhone deve essere registrato in anticipo tramite il suo UDID.

iOS 0.6 Recupero UDID dall'iPhone (obbligatorio)

L'UDID è l'identificativo univoco del telefono. Senza UDID registrato, l'IPA Ad Hoc non si installa. Inviare l'UDID al Chief TOC almeno 24–48 ore prima dell'evento.

Metodo A — iPhone collegato a Mac (consigliato)

  1. Collega l'iPhone al Mac con cavo USB (accetta «Fidati di questo computer»).
  2. Apri Finder → seleziona l'iPhone nella barra laterale.
  3. Sotto il nome del dispositivo, clicca ripetutamente su Numero di serie finché compare Identificatore (UDID).
  4. Tasto destro sull'UDID → Copia → invia al TOC (email / messaggio con nome squadra).

Metodo B — Xcode (tecnico Mac)

  1. Xcode → menu Window → Devices and Simulators.
  2. Seleziona l'iPhone collegato → campo Identifier = UDID → copia e archivia.

Metodo C — Volontario senza Mac

  • Porta l'iPhone al punto TOC il giorno prima: il tecnico legge l'UDID con Finder/Xcode.
  • In alternativa il TOC può fornire un link profilo temporaneo (MDM/UDID collector) da aprire in Safari — solo se preparato dal tecnico.
Apple non mostra l'UDID completo nelle Impostazioni iPhone in modo diretto. Senza Mac o assistenza TOC l'installazione Ad Hoc non è possibile: usare TestFlight se disponibile.

iOS 0.7 Registrazione dispositivo (Chief TOC / tecnico Mac)

  1. Accedi a developer.apple.com → Certificates, Identifiers & Profiles → Devices.
  2. + nuovo dispositivo → incolla UDID → nome descrittivo (es. GT_SM_01-iPhone15).
  3. Rigenera il Provisioning Profile Ad Hoc includendo tutti i dispositivi registrati.
  4. Ricompila l'IPA in Xcode con il profilo aggiornato (Product → Archive → Distribute → Ad Hoc).

iOS 0.8 Installazione app su iPhone

Opzione 1 — Ad Hoc (distribuzione evento)

  1. Il TOC invia link di installazione IPA (o file via AirDrop/email se previsto).
  2. Al primo avvio: Impostazioni → Generali → VPN e gestione dispositivo → seleziona certificato sviluppatore → Fidati.
  3. Apri gestSQUADRE dall'icona home.

Opzione 2 — TestFlight

  1. Ricevi invito email dal TOC / App Store Connect.
  2. Installa l'app TestFlight dall'App Store → accetta invito gestSQUADRE → Installa.

Opzione 3 — Xcode diretto (solo tecnico, test pre-evento)

  1. Mac con progetto app_mobile/kmp/iosApp → iPhone collegato USB.
  2. Xcode → seleziona iPhone → Run (⌘R). Utile per verifiche, non per tutta la flotta.

ENTRAMBI 0.10 Checklist pre-servizio volontario

  1. App gestSQUADRE installata e si apre senza errori.
  2. Posizione consentita.
  3. Notifiche consentite.
  4. Android: disattivato «Rimuovi autorizzazioni se l'app non viene usata» (§0.4b).
  5. Login di prova con codice squadra e password forniti dal TOC.
  6. In home: indicatore Push TOC: attiva (verde). Se rosso → Ripara push TOC.
  7. Il TOC vede la squadra online sulla dashboard.

2. App mobile — Volontari (uso operativo)

Per installazione APK/IPA e permessi vedi sezione §0. Le procedure sotto valgono per Android e iOS (stesse funzioni operative).

2.1 Login squadra

  1. Apri gestSQUADRE → attendi splash → home.
  2. Login squadra → codice + password.
  3. Consenti posizione e notifiche.
  4. Verifica Push TOC: attiva (verde). Se rosso: Ripara push TOC.
  5. Il login viene registrato nel log evento (tipo «Login squadra»).

2.2 GPS

Con login attivo la posizione è inviata al TOC automaticamente. Il GPS non compare nel log eventi.

2.3 Ricezione messaggio TOC

  • Notifica sul telefono (sirena se allarme).
  • Testo nel pannello blu in home.
  • Se missione TRK: via visibile sulla mappa tattica.

2.4 Allarme volontario → TOC (mappa rossa)

Non invia SMS/push al TOC. Evidenzia la squadra in rosso sulla mappa centrale.

  1. Pulsante allarme / segnala su mappa TOC.
  2. Seleziona: Ambulanza, Medico, DAE, FORZE DELL'ORDINE (giallo), V.V.F. (giallo), Altro (testo obbligatorio).
  3. Conferma → TOC vede allarme in colonna «Allarmi volontario».

2.5 Reset notifica

Azzera solo il pannello blu sul telefono. Registra log registrato. Non chiude allarme o missione sul TOC.

2.6 Logout

Logout dalla home, oppure logout forzato dal TOC. Ogni logout volontario o forzato viene registrato nel log evento (tipo «Logout squadra»).

3. TOC web — Operatori

3.1 Dashboard (3 colonne)

3 — Missioni TOC attiveVia TRK + target assegnatiFine evento

La mappa è su schermo grande o stessa finestra (non più embedded in home).

3.2 Invio push / missione

  1. Invia allarme a squadre (push).
  2. Titolo e testo messaggio.
  3. Per missione: una squadra + via TRK + target waypoint (obbligatorio con via).
  4. Invia → push mobile + via su mappa + log inviato.

3.3 Fine evento (solo TOC)

  • Allarme volontario: colonna 2 → Fine evento → allarme chiuso, log chiuso, pannello mobile azzerato (FCM).
  • Missione: colonna 3 → Fine evento → via rimossa, log missione chiuso, pannello mobile azzerato.

3.4 Log evento

Menu Log evento → elenco cronologico, export CSV/PDF. Include anche login e logout squadre, reset notifica mobile, allarmi, missioni e chiusure TOC. Solo admin può cancellare tutti i log.

4. Regole definitive Volontario vs TOC

4.1 Stati evento

StatoSignificatoChi
inviatoEvento aperto, visibile su TOC e/o mobileInvio iniziale
registratoReset notifica sul telefonoSolo volontario
chiusoEvento concluso ufficialmenteSolo TOC

4.2 Flusso A — Volontario → TOC

  1. Volontario segnala → inviato
  2. TOC vede rosso + colonna allarmi
  3. (Opz.) reset notifica mobile → registrato — allarme TOC resta aperto
  4. TOC «Fine evento» → chiuso

4.3 Flusso B — TOC → Volontario

  1. TOC push (+ eventuale TRK) → inviato
  2. Mobile: notifica + pannello + via su mappa
  3. Volontario esegue; (consigliato) segnala Altro al TOC
  4. Reset notifica → registrato — missione TOC resta aperta
  5. TOC «Fine evento» missione → chiuso
Errori da evitare: il reset notifica mobile NON chiude missioni/allarmi sul TOC. Solo «Fine evento» dal TOC chiude e registra la chiusura nel log.

Checklist TOC (giorno evento)

  1. Verificato che tutti i volontari abbiano app installata e permessi attivi (§0).
  2. Login TOC, evento attivo.
  3. Mappa su schermo grande (secondo monitor).
  4. Verifica squadre online e log login/logout in «Log evento».
  5. Push missioni: squadra + via + target.
  6. Monitora allarmi (col. 2) e missioni (col. 3).
  7. Fine evento su ogni riga gestita.
  8. Export log CSV/PDF a fine giornata.

Checklist volontario

  1. Completata checklist installazione e permessi (§0.10).
  2. Login, GPS e push attiva (verde).
  3. Allarme mappa solo se serve evidenziare al TOC.
  4. Dopo ordine TOC: esegui, eventualmente «Altro», poi reset notifica.
  5. Reset notifica ≠ «ho finito» — aspetta Fine evento TOC.
